# GUIDE – Gyroscopically-balanced Unmanned Indoor Direction-finding Escort  

This project has been developed with the intent of producing a self stabilizing diwheel or "Segway" style robot. Contained within the file are the following:  

1. A research paper detailing the efforts to produce this project, containing the informed decisions we made regarding CAD design, build specifications, physics modelling, controls setup, and guidance development.  
2. Video recordings to instruct project use and detailing the project's performance.  
3. Design information: CAD, Bill of Materials, and Working Sketches
4. Code containing all files required to be uploaded to the robot for performance.  
5. Code containing modelling information relevant to AI training and implementation.
